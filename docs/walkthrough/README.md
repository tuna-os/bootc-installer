# Installer frontends: walkthrough and parity

Generated by `shared/walkthrough/aggregate.py` from each frontend's own
screenshot job. Every frame is rendered in CI from the real UI, never
hand-taken, so this page cannot drift from the apps. Do not edit by hand.

## Parity matrix

Which screens of the shared contract each frontend reaches, as measured by
reading the visible widget text of every captured page against
`shared/walkthrough/parity_report.py`. ✅ reached · ❌ required screen not
reached · ⚠️ optional screen not reached · ➖ not measured (this frontend's
harness does not read its widget text yet) · ⏳ no capture on record.
